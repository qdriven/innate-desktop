# Native Chat Interface

The **Native Chat Interface** is a structured UI overlay that renders AI agent conversations as high-fidelity chat messages within terminal tabs. It transforms raw ANSI terminal output or journaled SQLite sessions into a conversation view featuring message bubbles, interactive question cards, tool-run summaries, background tasks, and subagent rosters. 

---

## Technical Constraints and Safety

- **Journal Persistence Verification**: Sessions must verify backing store validity via `hasPersistedStructuredAgentSessionStore` before launching structured service hosts [src/main/runtime/structured-agent-session-runtime.ts:70-85]().
- **Draft Preservation**: Draft scope keys prevent text loss during workspace reconnections and PTY lifecycle swaps [src/renderer/src/components/native-chat/NativeChatComposer.tsx:78-85]().
- **Adapter Safety**: Provider acquisition failures throw controlled acquisition refusals (`AgentSessionAcquisitionRefusal`) rather than degrading unhandled promise rejections [src/main/native-chat/agent-session-wire/structured-agent-session-adapter.ts:68-86]().
